# Marketing Campaign

## When to use
Use when creating a campaign (launch, seasonal sale, category push, cart
recovery), writing landing pages or ads, setting up email sequences, or
planning measurement for the zubeli storefront.

## Core rules
- Plan in order: goal (sales? signups? category awareness?) -> audience
  (contractors, DIY homeowners, workshops) -> channels (search, social,
  email, word-of-mouth) -> offer -> landing page -> measurement.
- One goal per campaign; every asset (ads, emails, landing page) drives the
  same single CTA.
- Landing page structure: headline with benefit -> proof (ratings, brands,
  delivery) -> offer -> product/CTA -> FAQ/social proof -> trust badges
  (returns, warranty). One CTA, above the fold.
- Ad copy: hook (problem/seasonal need) + benefit + offer + CTA; construction
  angle — durability, price, bulk discounts, delivery speed for sites.
- Email sequences: welcome (discount incentive), cart recovery (24h, 72h),
  post-purchase (thanks, reorder, review), seasonal sale. Subject line +
  preview text written first; plain-language body.
- Tracking: UTM on every outbound link
  (`utm_source=facebook&utm_medium=cpc&utm_campaign=tool-sale`); consistent
  naming (source/medium/campaign/term); measure revenue per channel, not
  just clicks; use the dashboard's sales data for attribution.
- Launch checklist: offer live -> UTM links tested -> landing page QA
  (mobile, checkout flow) -> emails scheduled -> analytics event firing ->
  launch -> check results within 48h -> iterate.
- Seasonal ideas: pre-construction-season (tool kit bundles), rainy-season
  (protective gear), festive sales (holiday discounts), stock-clearance
  events for slow-moving tools, volume discounts for contractors.

## Do NOT
- Do not run a campaign without UTM parameters or a defined success metric.
- Do not launch a campaign that routes to a page without the offer visible.
- Do not spam: cap email frequency, honor unsubscribe immediately.
- Do not set an unrealistic budget/channel mix without past sales data.
