# Zubeli — MVP Demo Release Notes

*For the client demo · 2026-08-08 · milestone: storefront + owner dashboard complete, full test coverage green*

## What's in this demo

Zubeli is one app with two sides:

- **Storefront (customers)** — browse the catalog (search, filters, categories), product pages with stock status, cart, checkout with **Pay on Delivery**, customer accounts with order history.
- **Owner dashboard (`/admin`)** — overview KPIs, product management (create / edit / publish / delete), stock levels + adjustments + movement history, orders with the full status lifecycle (confirm payment → fulfill → cancel / refund), customers list + purchase history, sales reports (overview + period).

## How to run

Full step-by-step (non-technical, screenshots-free plain language): **`docs/RUNBOOK.md`**.

Quick start:

```bash
docker compose up -d                  # 1. start the database
npm run db:migrate && npm run db:seed # 2. apply schema + demo data (seed is safe to re-run)
npm run dev                           # 3. open http://localhost:3000
```

## Known limitations (this demo)

- **Payments are Pay on Delivery only**, three options: cash at delivery, mobile money (MTN MoMo / Airtel Money code at the door), or bank transfer with **manual verification** by the owner in the dashboard. A live payment gateway (MTN MoMo / Airtel) will be integrated after the contract is signed — the code already has the hooks for it.
- **Demo data scale:** stock KPI numbers are exact for the current catalog (30 products); the numbers are computed from the first 100 rows and would need a small backend addition once the catalog exceeds 100 products (backlog item M1). Customers KPI cards show "rows loaded so far" per page (M2). Several minor UX items are tracked in the backlog (L1–L5 + storefront carry-overs) — none block the demo.
- **Demo data only** — reseed any time with `npm run db:seed` (idempotent, keeps 30 products / 15 orders).
