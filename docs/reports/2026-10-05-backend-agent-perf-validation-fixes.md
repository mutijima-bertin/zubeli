# 2026-10-05 — backend-agent — perf + validation + upload hardening

**Files:** `src/lib/db/categories.ts`, `src/lib/validation/category.ts`, `src/app/api/admin/upload/route.ts`, `tests/unit/validation.test.ts`, `tests/unit/storefront.test.ts` (+ this report).

- **F1 dedup (HIGH):** `listAll` normalizes the empty filter (bare / `{}` / all-undefined, e.g. the catalog's unfiltered `listFilters`) onto a frozen module singleton, then delegates to a `React.cache`-wrapped read (`queryActiveCategories`). The RSC `cache` keys object args by **WeakMap reference** (`node_modules/react/cjs/react.react-server.development.js:561-580`), so layout `listAll()` and the homepage/catalog page call in one request share **one** `findMany` + count aggregate instead of two. Stable key = the singleton; non-empty filters keep distinct keys. No dispatcher (Vitest) → passthrough, unchanged.
- **F2 over-fetch (MEDIUM):** dropped `description` from the storefront `select` **and from `CategoryWithCount`** — no storefront consumer read it. Admin shape untouched: `AdminCategory`/`listCategoriesForAdmin` keep `description`. Contract change: `CategoryWithCount = {id,name,slug,productCount}`.
- **F3 strict (MEDIUM):** `.strict()` on `createCategorySchema`/`updateCategorySchema` (zod v4 confirmed; unknown key → `unrecognized_keys`). The auto-derived slug was already re-parsed through `slugField` (min 2 + charset), so `name: "-a"` → `"a"` is rejected at `slug`. Tests added: unknown key rejected (both schemas), 1-char derived slug rejected, rename-without-slug leaves no slug key (DB behavior already covered in `admin-categories.test.ts`).
- **F4 upload (MEDIUM):** a body with no `content-length` (chunked) is piped through a byte-capped `TransformStream` (2 MB + 64 KB slack) and parsed via a new `Request`, so `formData()` aborts mid-stream; overflow → 413. Declared-length pre-check unchanged; a lying small `content-length` still falls back to the authoritative `File.size` check (comment added). Auth guard, MIME/ext allowlist, magic-byte sniff and 2 MB cap untouched.
